# h3d-assets: ассеты 3D-клиента HotA

Модели и текстуры Godot-клиента [h3d](https://github.com/3doops/h3d). В h3d этот репозиторий подключён
submodule'ом в `client/assets`, поэтому пути внутри него совпадают с путями в игре: `res://assets/models/...`,
`res://assets/terrain/...`.

| Папка | Что там |
|---|---|
| `models/*.glb` | модели объектов карты, существ, героев, городов (GLB, Y вверх, 1 клетка = 1 м) |
| `models/manifest.json` | ключ объекта (`def:<имя>`, `obj:<класс>:<подтип>`, `creature:<id>`, `hero:class:<id>`…) → GLB + размер в клетках |
| `terrain/*_albedo.jpg` | текстуры почв |

Клиент читает эти файлы как есть, во время работы (`GLTFDocument`, `Image.load_from_file`), а не через импорт
редактора: в папках лежит `.gdignore`, при экспорте сборка h3d кладёт их в `.pck` без конвертации.

Большинство моделей делает конвейер `assets3d/` в репозитории h3d. Он сам пишет сюда новые GLB и `manifest.json`.
Модели, исправленные вручную, тоже хранятся здесь.

## Работа с репозиторием

Файлы `*.glb`, `*.jpg`, `*.png` хранятся в Git LFS: в истории git остаются только ссылки. Нужен
[git-lfs](https://git-lfs.com), один раз выполнить `git lfs install`.

```sh
git clone --recursive https://github.com/3doops/h3d.git     # клиент + ассеты
cd h3d/client/assets                                         # дальше — обычный git
git switch main
```

Замена модели — положить новый GLB под тем же именем, закоммитить, запушить. Новая модель — GLB плюс строка в
`manifest.json`: каждый `res://assets/models/X.glb` из manifest должен существовать, сборка это проверяет. После пуша
сюда в h3d нужно закоммитить новую ссылку на submodule (`git add client/assets`), иначе сборка h3d возьмёт старую
версию ассетов.

GLB не сливаются. Если над одной моделью работают двое, займите файл перед правкой:

```sh
git lfs lock models/castle.glb       # остальные увидят блокировку: git lfs locks
git lfs unlock models/castle.glb     # после пуша
```

Квоты: хранилище и скачивание LFS считаются на аккаунт владельца (на бесплатном плане по 10 GiB в месяц). Сборка
h3d в GitHub Actions кэширует LFS-объекты и скачивает только изменённые файлы.
